CircuiTikZ circuits to SVG and PNG.
No TeX install. JavaScript, Python, Rust or the terminal.

voltik is a library of tikra: tikra draws the TikZ, voltik adds the CircuiTikZ components, and mathra typesets the math in labels. Above is Chua's circuit of 1983, a handful of parts that behave chaotically, drawn by voltik in your browser on every move with the values of a real build. Turn R down and the trace goes from a still point through a loop to the double scroll; drag the screen to turn it.

Why voltik

    
A small library on top of tikra, the same output everywhere: JavaScript, Python, Rust and the terminal.

    

      

        

        
No TeX install

        
No LaTeX, no CircuiTikZ, no system fonts, no external process. A single binary, a wheel, an npm package or a crate, all built from this repository.

      

      

        

        
Labels as CircuiTikZ puts them

        
Above, below, straight or turned with the component, with units written 10<\micro\farad>; the math typeset by mathra in Latin Modern Math, the same on every machine.

      

      

        

        
Warnings, not errors

        
A component voltik does not draw yet (a diode, here) is listed as a warning, and the rest of the circuit is drawn.

      

      

        
— ms

        
Fast and stable

        
Mean time to draw a corpus figure, measured in this page. The same input always writes the same bytes.

Use it

    
Pick your platform. All four packages run the same core, so a figure gives the same SVG, byte for byte, wherever it is converted.

    

      

        
JavaScript and TypeScript
npm

        
Node, bundlers (Vite, webpack, esbuild) and browsers. Types included.

        npm install @mathlabs/voltik

import { init, circuitikzToSvg, render, png } from "@mathlabs/voltik";

await init();  // browsers and bundlers; Node needs nothing
const svg = circuitikzToSvg(String.raw`\begin{circuitikz}\draw (0,0) to[R=$R$] (2,0);\end{circuitikz}`);
const { warnings, alt, description } = render(code);  // and the figure in words
const bytes = png(svg, { dpi: 300 });

      

      

        
Python
PyPI

        
Python 3.9 and later, with wheels for Linux, macOS and Windows. Types included.

        pip install voltik

import voltik

svg = voltik.circuitikz_to_svg(r"\begin{circuitikz}\draw (0,0) to[R=$R$] (2,0);\end{circuitikz}")
open("circuit.png", "wb").write(voltik.png(svg, dpi=300))
voltik.render(code)["warnings"]
voltik.render(code)["description"]  # the figure in words

      

      

        
Terminal
crates.io

        
One binary: a .tex file or stdin to SVG or PNG.

        cargo install voltik-cli

voltik circuit.tex -o circuit.svg
voltik circuit.tex -o circuit.png --dpi 300
voltik circuit.tex -o circuit.png --transparent
cat circuit.tex | voltik --warnings
voltik circuit.tex --describe

      

      

        
Rust
crates.io

        
The core itself, for servers and native apps; its LIBRARY can also be given to tikra next to other libraries. API docs on docs.rs.

        cargo add voltik

let out = voltik::convert(code)?;
std::fs::write("circuit.svg", &out.svg)?;
std::fs::write("circuit.png", voltik::png(&out.svg, 300.0, true)?)?;

      

    


    

      
What it reads

      
A circuitikz environment, or a tikzpicture that uses CircuiTikZ components, alone or in a full standalone document; everything tikra reads is read too, so TikZ and CircuiTikZ mix in the same figure.


      
What it draws

      
Path-style components placed with to[…]: short, open, generic, resistors (R, American and European), capacitors (C) and inductors (L, cute); labels and annotations (l, l_, a, R=label) straight, rotated or smart, with the siunitx shorthand 20<\ohm>; poles o and *; mirror and invert; \ctikzset and the class keys. The specification is the CircuiTikZ manual; what is drawn and what is not yet is in spec/subset.md.


      
How it is checked

      
Each circuit of the corpus is drawn by CircuiTikZ itself in TeX Live and by voltik, and the two are compared: the shapes by their coordinates, the labels by where their ink falls. TeX is only the reference to compare with; the behavior comes from the manual.
